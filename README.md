# AGE OF ASCENSION

*A Living VRMMORPG Simulation*

---

## Ten thousand years ago, the Divine War shattered reality.

Continents broke apart. Civilizations fell. Gods perished. Reality itself fractured.

From the ruins emerged The System — a divine framework that allowed mortal races to survive, grow stronger, and rebuild a broken world.

Today, the world continues to evolve.

Ancient ruins resurface. New dungeons emerge. Monster populations migrate and adapt. Political powers rise and fall. Trade routes shift. Forgotten gods leave traces behind.

**The world is alive.**

And it does not wait for you.

## Help Commands

Use the following commands at any time:

- `/help` — Gameplay assistance
- `/character` — Character sheet
- `/status` — Current status
- `/inventory` — Inventory
- `/skills` — Skills and abilities
- `/reputation` — Reputation standings
- `/quests` — Active objectives
- `/save` — Generate campaign save
- `/load` — Load previous campaign

---

## Save & Load

You can save your campaign at any time using:

```text
save
```

or

```text
/save
```

This generates a compact save containing:

- Character progression
- Equipment
- Skills
- Reputation
- Relationships
- Active discoveries
- World state
- Ongoing story threads

To continue later, simply paste the save file into a new chat and type:

```text
load campaign
```

or

```text
/load
```
